# 独立奖励入口

入口：agentic_text2sql.rewards.scoring.compute_score

流程：
1. 解析ground_truth / extra_info。
2. 使用SPIDER_DATABASE_ROOT解析并约束db_id对应路径。
3. 计算最终SQL执行指标。
4. 计算工具过程和重复调用指标。
5. 使用正确性门控公式组合奖励。

## 来源

工具过程解析原样迁入；重复调用提取来自历史V3的纯函数。
仅保留V10需要的派生指标，不导入V2–V10历史模块链。
部分历史指标键保留以便对照，不代表按历史版本组织代码。

## 明确的接口差异

- 不输出历史结构相似度及其他奖励版本的得分字段。
- 显式要求SPIDER_DATABASE_ROOT，不读取服务器专用标记文件。
- 配置、路径和元数据错误直接抛出，避免掩盖为模型零分。
- SQL执行异常仍产生零正确性，额外输出数值evaluation_error。
- 这是标量V10入口，不提供TurnCredit张量和事件向量。

## 验证边界

合成轨迹测试验证分支接线，不代表真实工具事件经过在线执行。
尚未完成历史真实轨迹与旧V10的关键字段对照。
尚未验证Reward Manager加载、多进程环境传播和在线训练。

## 历史解析限制

过程解析基于文本标签和JSON规则，按最近未响应调用匹配返回；
不是支持任意并行调用的call_id匹配器。
某些缺少显式ok字段、但没有错误字段的JSON返回会被视为成功。
重复Schema请求按去空白和小写规范化判断。
本次保留这些行为，没有将其描述为严格协议校验或新增算法改进。
